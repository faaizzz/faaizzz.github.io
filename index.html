AI Gateway · AWS · Terraform

AWS AI Gateway with LiteLLM

A governed LLM gateway on AWS where a product team onboards an AI use case by editing one YAML file and opening a pull request. Terraform turns it into least-privilege IAM, an approved model route, a route-scoped gateway key and a budget; the gateway enforces them at runtime.

  • LiteLLM on ECS Fargate in front of Amazon Bedrock (EU inference profiles), traced in Langfuse
  • Invalid use cases rejected at terraform plan: unknown route, wrong data classification, missing owner or budget
  • Proven against a live account: model override, bad key and disallowed model denied; budget exhausted returns a hard stop
  • CI on every PR: fmt, validate, 31 Terraform test runs, policy tests, tflint, trivy and plan

BYOP — Bring Your Own Podcast

A self-hosted app that turns the feeds, pages and searches you care about into a scheduled, multi-speaker AI podcast with its own public RSS feed. Bring your own model and voice keys, or run it all locally for free.

  • Pipeline from sources to episode: collect, de-duplicate and rank stories, write a dialogue script, voice each speaker, mix with ffmpeg
  • Any LLM or TTS provider: OpenAI, ElevenLabs, OpenRouter, local Kokoro, or any OpenAI-compatible server
  • Cost tracking per call, run and show, Langfuse tracing, live run view, review before publishing
  • Docker Compose deploy; CI with lint, strict typing, unit and Playwright end-to-end tests
